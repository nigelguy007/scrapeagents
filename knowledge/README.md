# Knowledge folder

Each file here (`<agent-id>.md`) is injected into that agent's system prompt
on every request. Agents with a file present show a "course notes loaded"
badge in the sidebar.

**This folder ships empty by design.** The agents' full methodology already
lives in `agents/agents.js`, written in original language as general industry
knowledge — pricing/positioning, design systems, deconstruction method, AI
build workflow, delivery, client acquisition, scaling. That's the product.

Per the license covering this project, what's licensed is the *knowledge,
skills, methods, and general learning* from the source course — not its
specific copyrighted written materials, templates, or video transcripts. So:
this folder is a place for **your own original notes** (things you write
yourself, in your own words) if you want to extend an agent further. Don't
paste verbatim text, templates, or transcripts from any paid course into
these files — that's the one thing the license doesn't cover, and it's not
needed anyway; the agents are already fully built out in `agents/agents.js`.
